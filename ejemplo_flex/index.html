Cómo usarlo en clase

Abre un ejemplo, cambia una propiedad en css/estilos.css y recarga el navegador. Para diseño adaptable, utiliza DevTools → modo dispositivo y prueba varios anchos.

Los ejemplos de CSS nativo funcionan sin internet. Las páginas Bootstrap y Tailwind utilizan bibliotecas en línea y necesitan conexión.
