02 · Flexbox

Flexbox: organización en un eje

Flexbox es útil para navegación, alineación y grupos de controles. Prueba las propiedades directamente en la hoja CSS.

1. Menú con Flexbox (diapositivas 5 y 6)

Se combinan justify-content: space-between y align-items: center.

Mi aplicación
InicioServiciosContacto
.menu {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 1rem;
  flex-wrap: wrap;
}

2. Botones centrados (diapositiva 7)

.acciones {
  display: flex;
  justify-content: center;
  align-items: center;
  gap: 12px;
  flex-wrap: wrap;
}

Prueba: cambia justify-content: center por space-between. Reduce el ancho de la ventana y observa cuándo los elementos pasan a otra línea.

3. Ejes de Flexbox

flex-direction: row coloca los elementos horizontalmente (eje principal horizontal). Con column, se apilan verticalmente (eje principal vertical).
